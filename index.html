THE GARDEN JOURNAL

What’s New?

A changelog of features and improvements in Scripture Paws.

OCT 2026 · RELEASE 1, PASS 7 UPDATE

A wider botanical collection

  • Expanded the collection beyond flowers with oak, cherry, and willow trees plus ivy, flowering, and grape vines.
  • Typing rewards now rotate through all 14 botanical varieties, while older flower records remain available.
  • Added distinct local pixel-art tree and vine sprites and included them in offline caching.
OCT 2026 · RELEASE 1, PASS 6

Garden scene & flower journal

  • Added flower-bed details, stepping stones, and more layered garden scenery.
  • Introduced eight distinct local flower sprites for the garden and collection.
  • Added Recent Blooms and Flower Varieties views, including per-variety collection counts.
  • Improved flower tile spacing, labels, and responsive layout; all artwork remains local for offline use.
OCT 2026 · RELEASE 1, PASS 5 UPDATE

Larger, more detailed garden cats

  • Redrew all four companions on a larger 96px pixel-art canvas with extra coat markings, facial detail, paws, and accessories.
  • Made each cat more visually distinct: Miso's ginger tabby stripes and flower scarf, Luna's charcoal coat and moon charm, Clover's calico patches and leafy collar, and Pip's cream coat and blue flower collar.
  • Increased sprite display sizes in the garden, buddy card, companion pill, and collection tiles while keeping responsive sizing.
  • Bumped the offline cache version so the refreshed artwork is picked up after deployment.
OCT 2026 · RELEASE 1, PASS 5

Garden cat sprite collection

  • Added four original transparent pixel-art cat sprites with distinct colors and accessories.
  • Added gentle idle motion, blinking, typing-progress reactions, and a completion celebration.
  • Updated the garden companion, buddy card, and collection tiles to use the new art.
  • Kept sprites local for offline use and honored reduced-motion preferences.
OCT 2026 · RELEASE 1, PASS 4

Living garden & cat companions

  • Added animated seedling growth, leaves, and a glowing bloom at completion.
  • Introduced four collectible garden cats with unlock milestones.
  • Expanded the flower reward variety and added a companion collection panel.
  • Improved motion preference support for the growing garden effects.
OCT 2026 · RELEASE 1, PASS 2

Douay-Rheims Scripture & garden polish

  • Added a starter selection of Douay-Rheims passages in quick-phrase and longer-practice modes.
  • Added verse references and edition labels.
  • Updated documentation about public-domain text and source attribution.
  • Kept personal progress, flower collection, WPM and accuracy tracking, and offline app-shell caching.
OCT 2026 · RELEASE 1, PASS 1

First Sprout

  • Introduced the typing practice engine with live WPM, accuracy, elapsed time, errors, and plant growth.
  • Added Miso, the first cat companion, and a flower collection.
  • Added local saving, personal bests, recent results, and garden-data export.
  • Created the responsive GitHub Pages structure and initial offline service worker.
OCT 2026 · RELEASE 1, PASS 7

Isometric garden worlds

  • Replaced milestone-based visitors with random rarity-based garden discoveries.
  • Build and save multiple gardens with up to 50 elements each.
  • Added isometric placement with footprint reservations and depth sorting to keep small creatures and flowers visible around trees.
  • Added a saved-garden gallery and local garden persistence.
